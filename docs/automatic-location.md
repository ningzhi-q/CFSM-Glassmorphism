# 自动 IP 属地与卡片金额修正

本次目标是让新加入的 VPS 自动定位，替代助手手工查询后写入标签。后端修改目标为用户的 `ningzhi-q/CF-Server-Monitor`，主题目标为 `ningzhi-q/CFSM-Glassmorphism`。

- 探针请求由 Cloudflare 提供可信城市 / 国家 / 经纬度，HTTP 与 WS 都在成功鉴权后保存。
- 新位置立即更新，同位置最多每 24 小时刷新；失败退避一分钟，不阻断指标上报。
- 公共 REST/WS 返回同一 `location` 扩展；不公开真实 IP，不把 `ip_v4` / `ip_v6` 当作地址。
- 主题自动位置优先于旧迁移标签，明确运营者位置优先于自动位置。缺数据时只显示国家中心。
- 国家中心不再重复国家名称。卡片信息自动换行，剩余价值金额完整显示。

校验记录见交付目录；部署使用原 Worker、数据库、DO 与静态资源绑定，数据库升级只惰性添加可空定位列，不运行全库升级接口。

本轮本地验证：lint、TypeScript、824 项测试、构建和 dist 结构检查通过；375 / 430 / 768 / 1024 / 1440 / 1920 六组视口的剩余价值芯片均完整，金额没有被裁切。后端 188 项测试（含真实 D1 SQL、HTTP/WS/REST 一致性）与 Agent 配置检查通过。
