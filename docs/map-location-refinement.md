# 城市细分与地图性能验收

本轮由用户要求「城市或地区 · 国家」、全选地图减少卡顿、图例顶部固定。一次性或永久节点隐藏剩余价值的前轮改动随本轮正式产物一起安装，保留购买价、购买合计与「∞ 永久」。

## 自动定位边界

新 VPS 在鉴权并提交有效指标后自动定位，不需要手工写标签或 IP 配置。Cloudflare 的城市缺失，或 HK 仅为 Hong Kong 时，后端从可信出口 IP 查询 [DB-IP 免费 API](https://db-ip.com/api/free)。同节点同 IP/位置在进程内缓存 24 小时，IP 或位置变化会查询；缓存有界，重启后可能重新查询。服务免费额度为调用方 IP 每日 500 次；超时或失败保留 Cloudflare 结果，不影响指标。

API 只提供名称，不提供坐标。本轮保留 Cloudflare 经纬度和 source；具体城市附 city_source，行政地区附 subdivision/subdivision_source。主题提示说明名称和坐标的不同来源；DB-IP 数据使用处附来源链接。香港地区不能当作机房位置，也不能仅靠 IP 确定物理机房。旧 WS 连接缺可信 IP 附件时需重连才能查询，HTTP 新上报立即识别。

## 地图与性能

42 台实际公开节点在 localhost 测试，每组运行 100 次纯指标更新，三次测量：桌面 105.5/96.0/84.2 ms 改为 46.0/51.8/27.9 ms；手机 98.9/91.2/163.3 ms 改为 32.6/24.5/33.1 ms。20 次全选/小集合切换耗时波动，未观察到稳定的同等提升，因此不宣称全选耗时减少特定比例。位置快照复用减少持续刷新开销，图例共用 blur 降低绘制负担。

标题和按钮保持原 y 坐标，列表 scrollTop 改变、panel scrollTop 为零；手机与桌面分别验证。成员详情导航解析最新节点。地图坐标、国家筛选和在线统计保持真实数据口径。

本地截图、性能原始结果及部署校验在本机临时验收目录，不进入正式包。
