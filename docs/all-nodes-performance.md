# 全部节点性能与地图名单验收

## 修改范围

本轮处理用户反馈的「全部节点」时整页交互卡顿、香港 Central 译名缺失，以及地图悬停名单每台 VPS 单独一行。无新增后端功能、请求或主题设置。

主要开销来自每根探测柱独立创建 Tooltip / Popper 组件，以及分组切换重新挂载卡片。现在每条色带共用一个真实 reka-ui Tooltip，采样柱仍全部绘制，指针和左右键可以查看各采样；点击仍使用原 ECharts 弹窗。适配层复用未变化的探测对象和不可变窗口转换，卡片仅在探测输入变化时重建色带。

全站超过 30 台使用 `RetainedServerGrid` 保留卡片身份，分组、搜索和快捷筛选控制显示。顺序不变的普通指标更新冻结隐藏卡片，重新显示时更新到最新数据。独立原生网格修正原 `TransitionGroup` 克隆 VNode 导致 memo 缓存未拿到 mounted el 的问题；小站保留原过渡，列表保留原实现。设置或排序变化仍按依赖刷新。

香港 `Central` 精确译为中环，仅适用于 HK；原行政地区、城市、来源与坐标不改动。地图提示用换行分隔 VPS，长名单在提示文字内部滚动，箭头在滚动区域外。

## 性能条件与结果

在同一台开发电脑上，以 Chrome 无界面模式、1440 × 1000 视口、生产方式构建的完整 App 测量；使用公开接口取得的 42 台快照，100 / 200 台仅复制该快照生成本地压力测试节点。停止实时连接并固定时间，避免网络和在线状态变动影响对比。压力测试副本、脚本和临时构建不进入正式资源。

每个操作执行三次，以下是墙钟耗时中位数（毫秒），包括 Vue 更新和两帧等待，不能视为真实访客 INP 或网络耗时。「整批指标对象替换」每次创建新的服务器对象，CPU / 网速参数相同，三次中的后两次值没有变化；它主要验证重复载荷及对象替换的开销，不代表每次都有新的探测采样。

| 节点数 | 整批指标对象替换：修改前 → 后 | 分组回全部：修改前 → 后 | 收藏筛选恢复：修改前 → 后 |
|---|---|---|---|
| 42 | 916.7 → 26.2 | 2080.1 → 147.0 | 847.2 → 165.8 |
| 100（副本） | 2584.7 → 50.2 | 6090.7 → 259.0 | 1752.8 → 262.8 |
| 200（副本） | 5116.1 → 46.5 | 13221.5 → 456.7 | 3623.1 → 459.4 |

42 台在 Chrome 四倍 CPU 降速下，中位数分别为 5372.5 → 49.6、16120.3 → 730.8、4361.0 → 648.3 毫秒。该降速只是模拟约束，不能等同于某款手机。

|---|---|---|
| 42 | 4238 → 248 | 4200 |

200 台仍有约 4.4 万个 HTML 元素。分组展开的测量仍记录到 363–537 毫秒长任务，四倍降速的 42 台分组展开也有 540–603 毫秒长任务。因此没有「完全不卡」的保证；此次显著减少组件更新和重复挂载，没有删减真实采样或改用整卡离屏占位。更多节点、较慢设备及极快滚动的绘制仍需要持续测量。

## 验收

- 本地 lint、typecheck、868 项单元测试、build、validate:dist 全部通过。
- 独立组件浏览器验收 399 项断言通过，覆盖 375 / 430 / 768 / 1024 / 1440 / 1920 明暗主题：地图名单逐台换行、40 台长名单内部滚动与边界；真实 0 / 18 / null / false / 200 采样、提示锚点、方向键、Escape、窗口更新与点击隔离。
- 最新完整 App 验收 313 项断言通过、无页面异常，同样覆盖六档视口与明暗主题：中环译名、同名属地去重、图例标题固定和列表独立滚动、分组和搜索结果、卡片身份复用、隐藏更新冻结及返回最新数值、真实探测图表、列表切换、四档密度、无横向溢出及长页面滚动。
- 长页面滚动断言验证页面确实移动和末卡内容存在，并人工检查手机顶部 / 桌面底部截图；这不是逐帧像素层面的无空白证明。此前极端快速滚动的绘制限制仍保留，未重新引入 `content-visibility` 或固定高度占位。
- 正式部署使用通过官方 GitHub Actions 全部质量门后发布的不可变 preview 提交，校验文件与 Git blob 字节一致后安装；部署后核验线上首页、资源、地图提示、实际中环译名、分组身份和探测弹窗。
