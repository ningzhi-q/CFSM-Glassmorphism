# 城市定位与分组联动

首页总览、费用汇总和地图使用当前分组、搜索与快捷筛选范围。地图国家筛选进一步作用于总览和节点列表；地图保留其他国家的淡化标记，提供当前范围的上下文。切换分组自动清除国家筛选；从地图进入详情再返回时保留浏览状态。

平面地图提供城市 / 节点与国家 / 地区两种图例。点击国家筛选，再点同一国家或“清除筛选”取消。悬停或键盘聚焦标记显示位置、在线数量与节点名称；点击标记或城市条目打开节点清单，点击节点进入所属数据源的详情。没有城市数据时显示国家中心，不猜测机房位置。

CFSM 公共接口不提供真实 IP。运营者可利用已有位置资料在服务器 `tags` 中明确提供：

```
geo-lat 34.05,geo-lon -118.24,geo-country US,geo-city 洛杉矶,geo-source legacy-ip
```

以上只是文档示例，不是生产数据。标签沿用 CFSM 现有清洗规则：英文逗号分隔、每项最多 32 字符、最多 12 项。经纬度必须同时存在、数值有效且在合法范围内，拒绝空值、非数值和 0/0 占位。城市是可选项；来源为 `legacy-ip` 表示旧 IP 属地参考，其余为运营者提供。坐标元数据解析后不当作普通装饰标签显示，原有用户标签保留。ASN 继续使用原主题的 `AS12345` 标签约定。

位置资料从公开 `tags` 进入 service adapter，随后供地理聚合器、地图和搜索使用。主题不查询外部 IP 服务，也不调用管理接口；实际位置会随换 IP 或迁机变化，需要运营者更新。IP 属地可能与节点名称或真实机房国家不同，因此界面明确显示来源。

国家主要名称内置中文，原始国家代码与服务器行政字段不改变。三个地球渲染器均读取同一位置聚合；上述点击与图例交互用于平面地图。

验收覆盖分组缩小后的在线数、速度与地图成员，国家筛选及清除，悬停 / 键盘标记信息，节点详情和返回状态，城市坐标校验，以及国家级降级。

## 2026-11-08：节点卡片与定位修正

- 地图、国家筛选统一使用 `serverMapLocation`。旧 IP 属地与后台登记国家冲突时回退到登记国家参考位置；不根据节点名称猜城市。显式运营者坐标仍受尊重。
- 用户要求的布局覆盖原版布局：CPU、内存、硬盘、负载四格；负载主值为 1 分钟，提示及副值为 5 / 15 分钟；进度按真实核心数计算。流量移到第三信息盒，到期与剩余价值移到芯片，原有隐私开关继续生效。
- 延迟与丢包色条使用 Reka 提示显示真实采样时间与数值，点击按钮打开 Reka 弹窗。弹窗复用 CFSM 公开列表的两小时采样，使用现有 ECharts / vue-echarts，保留缺口与未配置值，不发额外管理请求；完整历史仍由节点详情提供。
- 修正后台保存按钮悬停时底色被覆盖的问题；增加随滚动显示的返回顶部按钮，并尊重减少动画偏好。

- 后续用户补充：分组存入当前站点浏览器，刷新后恢复；在节点数据完整加载成功后才移除不存在的分组，避免启动加载期清空缓存。
- 手机改为整张世界地图在上、可独立滚动的双列城市／国家列表在下；列表按钮最小 44px，取消 42rem 强制宽度，手机页面无需横向滚动。

地图默认显示国家／地区列表，按钮在左侧；城市／节点按钮在右侧。地图国旗上方的交互触发区域完全透明，不再覆盖浏览器默认按钮外观。

### 分组自定义排序

点击分组栏右侧的上下排序图标，拖动每行左侧手柄或点击上下箭头调整（手机可直接触摸手柄拖动；按 Escape 可取消本次拖动），然后选择保存到此浏览器，或管理员设为站点默认。全部节点固定最前，刷新后保留自定义顺序；恢复默认会在保存后生效。主题设置 → 首页布局也可按行填写分组名。

自动属地现由 ningzhi-q 后端成功上报后提供，旧 `legacy-ip` 定位标签已按用户要求删除。城市名称以简体中文呈现，翻译与位置数据相互独立；详细来源和未知译名处理见 [城市中文化](city-localization.md)。
