# 城市定位与分组联动

首页总览、费用汇总和地图使用当前分组、搜索与快捷筛选范围。地图国家筛选进一步作用于总览和节点列表；地图保留其他国家的淡化标记，提供当前范围的上下文。切换分组自动清除国家筛选；从地图进入详情再返回时保留浏览状态。

平面地图提供城市 / 节点与国家 / 地区两种图例。点击国家筛选，再点同一国家或“清除筛选”取消。悬停或键盘聚焦标记显示位置、在线数量与节点名称；点击标记或城市条目打开节点清单，点击节点进入所属数据源的详情。没有城市数据时显示国家中心，不猜测机房位置。

CFSM 公共接口不提供真实 IP。运营者可利用已有位置资料在服务器 `tags` 中明确提供：

```
geo-lat 34.05,geo-lon -118.24,geo-country US,geo-city 洛杉矶,geo-source legacy-ip
```

以上只是文档示例，不是生产数据。标签沿用 CFSM 现有清洗规则：英文逗号分隔、每项最多 32 字符、最多 12 项。经纬度必须同时存在、数值有效且在合法范围内，拒绝空值、非数值和 0/0 占位。城市是可选项；来源为 `legacy-ip` 表示旧 IP 属地参考，其余为运营者提供。坐标元数据解析后不当作普通装饰标签显示，原有用户标签保留。ASN 继续使用原主题的 `AS12345` 标签约定。

位置资料从公开 `tags` 进入 service adapter，随后供地理聚合器、地图和搜索使用。主题不查询外部 IP 服务，也不调用管理接口；实际位置会随换 IP 或迁机变化，需要运营者更新。IP 属地可能与节点名称或真实机房国家不同，因此界面明确显示来源。

国家主要名称内置中文，原始国家代码与服务器行政字段不改变。三个地球渲染器均读取同一位置聚合；上述点击与图例交互用于平面地图。

验收覆盖分组缩小后的在线数、速度与地图成员，国家筛选及清除，悬停 / 键盘标记信息，节点详情和返回状态，城市坐标校验，以及国家级降级。
