# 城市名称的简体中文显示

三个地图渲染器、城市列表、位置提示和中文城市搜索共用 `formatCityNameZh`。后端自动上报的城市、国家及坐标保持原始值；中文化只发生在展示层，不手工改写位置或生成标签。

## 地名来源

- Komari Glassmorphism 的原有城市名称对照表继续优先使用，补齐当前自动上报的艾奥拉、成都、吉达、罗央、苏丹贝伊利、东涌。艾奥拉对应堪萨斯州的 Iola（本次上报坐标 37.92448 / -95.39998），中文名称参考[维基百科](https://zh.wikipedia.org/wiki/艾奧拉_(堪薩斯州))；苏丹贝伊利名称参考[维基百科](https://zh.wikipedia.org/wiki/蘇丹貝伊利)。
- 扩展地名来自 [GeoNames](https://www.geonames.org/) 的 [cities1000](https://download.geonames.org/export/dump/cities1000.zip) 数据，2026-11-08 下载，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。本主题提取人口不低于 15,000、中文别名在繁简转换后无歧义的记录，生成 10,244 个按国家隔离的名称别名。过滤、繁简转换和格式整理是本项目对源数据的修改。
- [OpenCC JS](https://github.com/nk2028/opencc-js) 1.4.2 用于繁简转换。源码与字典许可说明随 `assets/` 中的 city-data-licenses 文件分发，HTML 的 license 链接指向该文件。

## 数据边界

国家 + 原始城市名称必须精确匹配，大小写、空格、分隔符和重音字符作统一处理。同名城市只用原始坐标消歧，不通过最近坐标推测另一个城市。无可靠中文译名时显示「城市译名待补充」，仍保留真实坐标和原始城市用于内部识别及搜索。不会把英文直接回退到地图文字，也不会编造中文城市或物理机房位置。名称结果缓存有界（512 项），普通指标更新无需重复转换。

## 更新本地数据

下载并解压官方 cities1000.zip 后运行：

```sh
bun scripts/generate-city-gazetteer.mjs /absolute/path/cities1000.txt
```

生成命令输出 TSV 的 SHA-256。本轮源文件校验值为 `7ea73eacab9decae98df1b3f97dc8978959811815a8cfe6fea09104f9ceeaac2`。源 ZIP/TSV 属于临时开发资料，不提交；提取后的名称表是运行时源码数据。正式构建不下载外部地名库。浏览器在后台读取主题自身的压缩地名资源，严格校验后安装到只读名称索引；不会调用翻译或 IP 查询服务，也不阻塞探针数据加载。名称索引就绪会更新地图译名。

本轮另按用户要求清除带 `geo-source legacy-ip` 的旧迁移定位标签，保留所有其他标签、服务器配置和 `auto_location` 自动属地字段。删除前后备份和核验保存在本机交付目录。
