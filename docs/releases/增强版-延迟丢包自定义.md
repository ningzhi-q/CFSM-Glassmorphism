# 增强版：延迟／丢包自定义展示

首页卡片现在可以自定义探测线路：在「主题设置 → 节点卡片、列表与快捷控制」勾选线路，用手柄拖动或上下按钮排序，并选择单行／多行和近 1／2 小时。单行显示首个可用线路，多行显示所有选中的可用线路；全部取消会隐藏探测区。

每条线路都有延迟、丢包两列色带，使用所属站点的真实名称。平均值与色带按相同时间范围计算，无采样仍保留缺口，丢包为零正常显示。窗口不存在时明确提示最近一次上报；已有窗口过期或全缺口不会伪装成实时平均。

设置可保存到本机，管理员也可沿用主题设置的后端保存功能设为全站默认。不会自动生成 CFSM 未提供的 IPv6 探测任务，也不增加逐节点历史请求。
