# 城市标注与剩余价值显示修正

- 地图弹窗每台节点明确标注城市，悬停提示同步展示。香港节点的定位源返回 `Hong Kong`，显示「城市：香港」；没有更细区名时不按坐标猜测。
- 一次性计费或永久到期节点隐藏首页剩余价值芯片与详情剩余价值卡，财务明细对应单元格留空，并排除剩余价值合计。
- 购买价格和购买总价值保留；一次性月均为零，周期计费的永久节点仍按原周期计算月均。普通周期且非永久节点的剩余价值继续照常计算。
- 保留「∞ 永久」标识，无需新增设置，不修改现有节点账单、日期、通知或主题偏好。

验证：lint、typecheck、test（73 个文件、856 项测试）、build、validate:dist 全部通过；覆盖城市来源与缺失降级、一次性及永久的日期／价格组合、详情隐藏和混合节点财务合计。localhost 实际组件在 1440／375 宽、浅／深色下共 92 项检查通过：芯片隐藏、购买价与永久标识保留、明细留空、合计排除、城市标注与国家中心降级均符合，没有页面横向溢出或浏览器异常。
