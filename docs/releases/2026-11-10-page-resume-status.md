# 切回页面在线状态优化 · 2026-11-10

页面隐藏后，原在线过期计时器仍在运行，会把停止接收实时更新的旧数据判为离线。现在后台同时停止连接、回退轮询和过期检查；切回先提示「正在更新节点状态」，保留最后一次收到的数据，完成 REST 刷新后恢复在线判定与实时连接。

五分钟离线阈值不变，刷新失败也会结束恢复状态并如实标记过期节点。快速来回切换和手动刷新共用请求，不增加后台轮询、逐节点请求或长期连接。

本轮为 1 项 🟢 等价修复，无新增降级或不支持项；主题设置仍为 53 项。现有 CFSM 公开接口与多 API Base 来源归属不变。

验证：lint、Vue 模板 typecheck、74 个测试文件／872 项测试、build、dist 校验全部通过。新增回归覆盖后台六分钟、延迟 REST、真实时间戳更新、请求失败、快速切换、暂停／超时和计时器清理。本地浏览器验证恢复提示与真实离线提示切换、后台无活跃计时器、每次恢复仅一组请求及一次订阅；375px 手机视图无横向溢出。

正式产物由 GitHub Actions 构建并发布至不可变的 preview commit，部署只更新主题 URL。
