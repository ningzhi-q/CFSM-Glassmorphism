# 增强版：节点卡与定位修正

## 2026-11-08：节点卡片与定位修正

- 地图、国家筛选统一使用 `serverMapLocation`。旧 IP 属地与后台登记国家冲突时回退到登记国家参考位置；不根据节点名称猜城市。显式运营者坐标仍受尊重。
- 用户要求的布局覆盖原版布局：CPU、内存、硬盘、负载四格；负载主值为 1 分钟，提示及副值为 5 / 15 分钟；进度按真实核心数计算。流量移到第三信息盒，到期与剩余价值移到芯片，原有隐私开关继续生效。
- 延迟与丢包色条使用 Reka 提示显示真实采样时间与数值，点击按钮打开 Reka 弹窗。弹窗复用 CFSM 公开列表的两小时采样，使用现有 ECharts / vue-echarts，保留缺口与未配置值，不发额外管理请求；完整历史仍由节点详情提供。
- 修正后台保存按钮悬停时底色被覆盖的问题；增加随滚动显示的返回顶部按钮，并尊重减少动画偏好。

- 后续用户补充：分组存入当前站点浏览器，刷新后恢复；在节点数据完整加载成功后才移除不存在的分组，避免启动加载期清空缓存。
- 手机改为整张世界地图在上、可独立滚动的双列城市／国家列表在下；列表按钮最小 44px，取消 42rem 强制宽度，手机页面无需横向滚动。
