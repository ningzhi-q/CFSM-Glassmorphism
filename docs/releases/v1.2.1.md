本版本配合 CFSM 后端动态探测协议与新版 Agent，解除固定八路 Ping 槽位限制。后台可增删实际探测地址、命名分组，并为每台服务器选择自动或手动探测。

- IPv4 节点自动使用 IPv4 组，IPv6 节点使用 IPv6 组，双栈同时使用两组。通用组适用于任一种可用网络。
- 详情页可按组选择曲线；手动全不选不会被实时更新覆盖。卡片与主题设置支持动态节点及排序。
- 延迟 0、超时 null、关闭 false 分别保留，删除目标会清除实时快照。不同 API 来源分别使用自己的分组名称。
- 后端配置默认不开启动态探测，旧 Agent 和原八路配置保持兼容。启用后新版 Agent 使用动态目标。
- 探测采用四路并发且独立于资源采样，不阻塞 CPU、内存和流量上报；配置受传输大小限制，不设置固定节点数量。
- 保留页面切回时刷新状态的修复。

本地界面验证覆盖 18 个目标的增删、IPv4 自动选择、全不选后实时更新、切换同目标服务器恢复默认及 390px 手机宽度无横向溢出。
