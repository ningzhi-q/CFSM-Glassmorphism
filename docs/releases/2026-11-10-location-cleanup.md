# 地图弹窗与自动属地修复

- 删除地图弹窗节点行中的重复属地，标题保留；在线状态、节点名、分组和详情入口继续显示。
- 地图标题、城市列表及提示中的同名属地合并为「香港」「新加坡」。真实具体地区仍显示「九龙 · 香港」「淡滨尼 · 新加坡」等格式。
- 配套后端补查粗略的新加坡属地，将提供者返回的地区单独记录；查询失败一分钟后随下次有效上报重试，成功结果缓存一天。
- 缺少可信出口 IP 附件的旧粗定位连接在处理并确认当前上报后自动重连一次，取得元数据；新连接不会反复重连。

不新增设置项。地名来自可信上报与 DB-IP / IPapi.is，坐标继续采用 Cloudflare 参考。无法取得更细地区时保留原始属地。
