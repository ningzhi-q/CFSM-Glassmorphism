# 城市细分与地图流畅度修复

- 地图成员和城市列表改为「葵涌 · 香港」「春川 · 韩国」「洛杉矶 · 美国」格式。只显示实际已提供的城市或地区，缺失时如实提示。
- 配套后端自动补充粗定位；城市名称和行政地区分开记录，保留 Cloudflare 原始坐标与来源。无需手工配置节点属地。
- 固定地图列表上方的标题、在线率和切换按钮，只有节点列表滚动；电脑、手机一致。
- 减少全节点指标刷新时的重复聚合、提示计算及毛玻璃绘制。保留在线状态和位置即时更新，节点详情展示最新数据。
- 正式安装包含前轮的一次性/永久剩余价值隐藏，购买价格、合计和「∞ 永久」保留。

边界与验收见 [地图城市细分与性能](../map-location-refinement.md)。正式包由 Actions 构建，安装固定到该构建对应的不可变预览提交。
