# 主题设置增强审计

## 增强轮：延迟／丢包展示设置

新增 `probeDisplayMode`（默认 `single`）、`probeTargets`（默认八目标按 CFSM 顺序、换行存储）、`probeWindowHours`（默认 2，只支持 1 或 2）。现在 schema 为 52 项：48 项上游设置、分组顺序和本轮三项。设置页第五组提供单行／多行、时间范围、线路勾选与鼠标／触摸拖拽排序，手柄方向键及上下按钮可替代拖动。全部取消表示隐藏卡片探测区。

三项均走默认值 → 后端 `theme_options` → 本机覆盖三层；使用既有完整快照保存流程，无新写入口。设置编辑器使用主站探测名称，每台卡片仍使用所属 apiBase 的配置名称。单行取排序后的首个已配置目标，多行显示全部选中的已配置目标。未配置线路不展示，不生成 IPv6 任务。
