# 主题设置增强审计

## 增强轮：延迟／丢包展示设置

新增 `probeDisplayMode`（默认 `single`）、`probeTargets`（默认八目标按 CFSM 顺序、换行存储）、`probeWindowHours`（默认 2，只支持 1 或 2）。现在 schema 为 52 项：48 项上游设置、分组顺序和本轮三项。设置页第五组提供单行／多行、时间范围、线路勾选与鼠标／触摸拖拽排序，手柄方向键及上下按钮可替代拖动。全部取消表示隐藏卡片探测区。

三项均走默认值 → 后端 `theme_options` → 本机覆盖三层；使用既有完整快照保存流程，无新写入口。设置编辑器使用主站探测名称，每台卡片仍使用所属 apiBase 的配置名称。单行取排序后的首个已配置目标，多行显示全部选中的已配置目标。未配置线路不展示，不生成 IPv6 任务。

## 2026-11-09：计费与页脚定制

一次性和永久来自所属服务器公开账单字段，不新增主题设置。页脚按用户要求直接移除，设置仍为 52 项，三层归一化与完整快照保存契约不变。一次性默认永久和离线告警输入属于 `/admin#admin` 的主程序管理端，由主程序实现；主题不提供管理写入口。部署只更换主题产物 URL，保留现有 theme_options 和其它外观配置。

城市标注和一次性／永久隐藏剩余价值直接按公开数据生效，无需开关，仍为 52 项。剩余价值汇总排除不适用条目，购买价格和月均支出保留；不批量修改现有账单、到期日期或通知设置。

## 2026-11-09：细分属地与地图性能

本轮没有新增主题设置键。属地细分由扩展后端自动处理，主题读取公开 `location`；不在本机设置中填写 IP 或地区、不调用管理 API。图例顶部固定是用户要求的默认交互，国家/城市切换继续使用原交互。一次性/永久剩余价值隐藏仍是财务域行为，购买价格及合计保留。

2026-11-10：弹窗成员属地移除、同名去重及新加坡区域译名默认生效，仍为 52 项。自动补查和旧连接迁移由主程序执行，无需给新增节点手工填写地区或增加主题开关。


2026-11-10 备用定位：DB-IP 限流时由主程序自动查询 IPapi.is，无需手工配置 IP、城市或主题开关。主题设置仍为 52 项；仅消费公开的已验证来源元数据。

2026-11-10 全部节点性能：全站超过 30 台自动使用可复用网格，每条探测色带共用一个提示控件；地图名单逐台换行、香港 Central 显示中环，默认生效。仍为 52 项，探测单行／多行、目标顺序、近 1／2 小时及密度设置沿用三层配置，未增加性能或译名开关。部署只更新主题产物 URL，保留站点配置。


## 2026-11-10 · 首页交互反馈

新增 `nodeCardInfoFields`，默认 `uptime,price,expiry,remainingValue`，以复选框选择节点卡片名称下方的在线天数、价格／周期、剩余天数和剩余价值。空串表示全部隐藏；未知键被过滤，非字符串沿用下一层。schema 现为 53 项（48 项上游 + 分组排序、3 项探测配置、本项）。默认 → 后端 → 本地以及草稿预览均使用同一规范化规则；本地保存只影响当前浏览器，后端保存提交全部 53 项完整快照。价格隐私、后端 show_price/show_expire 和一次性／永久规则仍优先于显示选择。多 API Base 来源标识独立保留。

设置页滚动后在左下固定显示返回节点列表按钮，底部留出操作空间。时钟、滚动和间距修复默认生效，无新增开关。详见 [交互验收](dashboard-feedback.md)。

2026-11-10 页面恢复：隐藏时停止在线过期检查，切回先更新节点状态再恢复检查与连接，默认生效，没有新增设置。完整快照仍为 53 项；`dataUpdateInterval` 继续只控制可见页面的 REST 回退轮询。部署只更新已验证的主题产物 URL，保留其余站点设置。
