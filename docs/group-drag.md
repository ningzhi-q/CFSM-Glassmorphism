# 分组拖拽排序增强

日期：2026-11-09。范围为用户指定的首页「分组自定义排序」弹窗。

## 操作与保存

每行左侧的 Tabler `grip-vertical` 手柄可用鼠标或触摸拖动，列表边缘自动滚动。上下箭头继续保留；手柄聚焦时上下方向键也可移动。全部节点仍位于列表外，固定最前。

拖动时有浮动行和落点反馈。Escape、系统触摸取消、失焦、页面隐藏、关闭和卸载均取消当前拖动。拖动期间禁止保存，保存期间禁止改变顺序。关闭不保存草稿，重新打开读取已经保存的配置。

本机保存和管理员站点默认保存继续使用原有 `groupOrder`，不增加设置键或接口；保留当前不存在的已配置分组。站点保存仍由 store 读取最新配置，提交完整快照，保留未知字段并回读。主题没有新增请求。

## 实现与验证

- SortableJS 1.15.6 负责拖拽与自动滚动，延迟到排序弹窗加载；不替换 Reka UI 弹窗。放下时先恢复临时 DOM 顺序，再由 Vue 按名称 key 更新。实时指标刷新生成同内容的新分组数组时，不会中断拖动。
- `moveGroupTo` 负责跨位置插入，保持其它分组相对顺序，不修改原数组；无效位置不改变顺序。单元测试覆盖跨位置、首尾、特殊名称及边界。
- 本机 lint、typecheck、842 项测试、build、validate:dist 全部通过。产物为 `index.html` 与 32 个 assets 文件；JS 3275.5 KiB、CSS 120.1 KiB、全部 assets 6571.5 KiB，满足现有预算，未调整限额。
- 独立 localhost 浏览器完成 23 项检查：鼠标拖拽、原生手机触摸、列表自动滚动、Escape/touchcancel、再次拖动、箭头与键盘、固定全部节点、本机保存与刷新恢复、关闭丢弃草稿、不存在分组的保留、浮层清理和保存互斥。
- 375、430、768、1024、1440、1920px 弹窗无横向溢出，手柄至少 36px；无未捕获浏览器异常。生产默认分组顺序没有为测试而修改。
