| 反馈 | 原因／结果 |
|---|---|
| 筛选与分组间距 | 分组前统一留 12px；tiled 外层不再用固定最小高度，在线／离线国家总览卡数变化不会制造额外地图下留白 |
| 当前时间偶尔跳秒 | 原时钟依赖节点数据触发 computed，缺少独立计时器；现在单独使用上游 useNow 1000ms，停用或隐藏时暂停，恢复立即取真实当前时间 |
| 节点卡片信息自定义 | 新增 `nodeCardInfoFields`，四项勾选，默认全选，可全部隐藏；隐私、show_price/show_expire、一次性与永久规则仍生效，多 API Base 来源标识保留 |
| 返回顶部动画 | 480ms 三次缓出；用户操作可取消；系统减少动态效果时直接到顶 |
| 设置页固定返回 | 滚动后左下显示返回节点列表按钮，底部预留空间，不必滚回页首 |
| 地图列表滚轮陷住 | 移除 overscroll containment；内部滚到边界时转交本次滚轮未消费距离给页面，不重复滚动，不接管横向手势或 Ctrl/Meta 缩放 |
| IPapi.is 标签出现不一致 | 有 `citySource` 或 `subdivisionSource` 指向 IPapi.is 的节点才显示该署名；Cloudflare 已提供名称、运营者位置、国家中心参考等不能统一标成 IPapi.is。标签不代表物理位置精度 |
